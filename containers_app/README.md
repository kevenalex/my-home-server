# services

Uma pasta por serviço instalado no servidor. Cada pasta tem:

- `README.md`: o que o serviço faz, como instalar, como testar e como desfazer.
- `Dockerfile` / `docker-compose.yml` / arquivos de configuração, quando houver.

Ao adicionar um serviço novo: criar a pasta aqui, listar na tabela de serviços do [README central](../README.md) e, se houver contexto extra, adicionar uma nota em [`anotacoes/`](../anotacoes/).
